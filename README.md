# AI-Powered Image Captioning Bot (BLIP + Telegram)

An AI chatbot that accepts images via Telegram and returns human-like captions generated by the **BLIP** Vision–Language Model.

---

## Features

- 📸 Send any photo → get an automatic AI-generated caption
- 🧠 Powered by `Salesforce/blip-image-captioning-large` (Transformer VLM)
- 💬 Optional conditional captioning — include a text hint with your image
- 📄 Supports both compressed photos and uncompressed document uploads
- ⚡ Simple Telegram bot interface (`/start`, `/help`, `/about`)

---

## Tech Stack

| Layer | Technology |
|---|---|
| VLM (captioning) | BLIP (`Salesforce/blip-image-captioning-large`) |
| Model framework | HuggingFace Transformers + PyTorch |
| Telegram integration | python-telegram-bot v21 |
| Image processing | Pillow |


### 4. Set your Telegram Bot Token
Get a token from [@BotFather](https://t.me/BotFather) on Telegram, then:
```bash

```

### 5. Run the bot
```bash
python bot.py
```

## How It Works

1. User sends a photo to the Telegram bot.
2. The bot downloads the image and converts it to RGB using Pillow.
3. The image (and optional caption hint) is passed to the BLIP processor.
4. BLIP's `BlipForConditionalGeneration` model generates a caption.
5. The caption is sent back to the user in the chat.

```
User photo → Pillow (RGB) → BLIP Processor → BLIP Model → Caption text → Telegram reply
```

## Notes

- The BLIP `large` model (~900 MB) is downloaded on first run via HuggingFace Hub.
- Use `Salesforce/blip-image-captioning-base` in `bot.py` for faster inference on low-spec machines.
- For GPU acceleration, ensure PyTorch with CUDA is installed.
